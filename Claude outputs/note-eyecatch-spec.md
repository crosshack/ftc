## 3. 配置ルール（重要）

**左＝アウェイ、右＝ホーム。** 北米の表記慣習（`Patriots at Seahawks`）およびNFL.comのボックススコアの並びに合わせる。

**アイコンは中央の区切り記号を基準に、絶対配置で左右対称に固定する。**

初期案はチーム名とアイコンを行として中央揃えしていたが、この方式では**左アイコンの位置が両チームの名前の長さの合計で動く**。並べたときに位置がバラつくため、中心からの距離で固定する方式に変更した。

構造は次のとおり。

```
[チーム名(アウェイ)][アイコン]   @   [アイコン][チーム名(ホーム)]
                            ↑固定  ↑固定
```

**検証結果**: チーム名の長短8パターン（最短4文字 `RAMS`/`JETS` 〜 最長10文字 `COMMANDERS`/`BUCCANEERS`、略称2文字×3文字の組み合わせを含む）すべてで、**左アイコンの内端が 522px で一致**。最長×最長のときに名前の左端が82pxとなり、日本語タイトルの左端80pxとほぼ揃う。**32チームどの組み合わせでも破綻しない。**

**既知の制約**: 最短×最短（`RAMS` @ `JETS` など）のときは左右の余白が大きくなる。カードごとに文字サイズを可変にすれば埋まるが、**並べたときに文字サイズが不揃いになる**ため固定54pxとする。

## 4. 色の扱い

**チームカラーはアイコンが持つため、別途の配色ルールは不要。**

NFL.DBのチームアイコンは「背景＝主色 / 下部バー＝副色 / 枠線＝第3色」の3色構造を持つ。この構造のおかげで、**主色が同一のチーム同士でも区別がつく**。

**ただしWEEKラベルにはブランド緑 `#3ecf6e` を使わない。** シーホークス（`#69BE28`）、ジェッツ、パッカーズなど緑系チームの回で、画面内に緑が2種類並んで競合するため。ニュートラルグレー `#8b938a` とし、緑はロゴ内のみに限定する。

**既知の制約**: `#002244` を主色とするチームが4つある（ペイトリオッツ・シーホークス・ブロンコス・カウボーイズ）。これらが対戦する回は、アイコンが2つとも紺の四角になり、**略称とバーの色だけが手がかり**になる。縮小表示では判別しづらい。

### 検討したが不要になったもの

C-3（チーム名の下にカラーライン）を検討した際、線に使う色を決めるためのルールを設計した。**C-5では不要**だが、将来チームカラーを線や文字に使う場面が出た場合のために記録しておく。

- **アイコンのバー色をそのまま線に流用することはできない。** 32チーム中9チーム（ジェッツ、ベンガルズ、ブラウンズ、ジャガーズ、ファルコンズ、パンサーズ、セインツ、バッカニアーズ、カージナルス）はバーが黒または黒に近く、暗背景では消える。
- 有効だったルール: **主色→副色→第3色の順に、(a) 暗背景での相対輝度 0.035以上、(b) 相手チームの色とのRGB距離90以上、を満たす最初の組を選ぶ。** 全992カード（ホーム/アウェイ別）で解決可能。うち10カードのみ、公式3色では解けず「白40%混色の明トーン」への退避が必要（ベアーズ・テキサンズ・ブロンコス・ベンガルズ・コルツ・レイダーズ・カウボーイズ・コマンダーズ・パッカーズ・バッカニアーズの一部の組み合わせ）。

## 6. 生成方法

`make_note_eyecatch.py` を使う。**リポジトリには書き込まない方針のため、クラウドセッション側で実行してPNGをチャットで受け渡す**（`claude-interaction-preferences.md` 参照）。

```
python3 make_note_eyecatch.py \
    --away NE --home SEA \
    --week "2026 WEEK 1" \
    --line1 "開幕戦を決めた、" \
    --line2 "カバー0ブリッツの1プレー" \
    --sep "@" \
    --out eyecatch.png
```

必要なもの: playwright（chromium）、`_setup/fonts/` のwoff2 7種、`assets/img/logo-combined.svg`。

## 7. 未決

**区切り記号を `@` と `vs` のどちらにするか。**

- `@` … 「アウェイがホームに乗り込む」という意味を持つため、**どちらがホームかが記号だけで伝わる**。北米の表記に忠実。
- `vs` … 日本の読者に馴染みがある。ただし並び順を知らない読者にはホーム／アウェイが判別できない。

スクリプトの既定値は `@`（`--sep` で切替可）。
