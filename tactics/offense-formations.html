シングルバック・フレックス SINGLEBACK FLEX

パーソネル: 11（RB1 / TE1 / WR3）

配置を隠しながら、ラン・パスどちらにも即応できる

RB1人をQBの後方に置き、TE1人・WR3人を外に配置する現代オフェンスの基本形。ラン・パスの均衡が取れており、守備にプレー予測をさせにくい。

構成内容
パーソネル11（RB1 / TE1 / WR3）
ポジション構成QB1・RB1（オフセット）・TE1（Y, 右インライン）・WR3（X, H, Z）。5人のOLに加え、6人の適格レシーバー候補（TE+WR3+RB）を確保できる、最もバランスの取れた並び。
特徴・用途ランとパスの選択肢を均等に持てるため、守備に人数・カバレッジの的を絞らせにくい。TEの有無だけでランかパスかのヒントを与えにくい「万能型」の隊形。
効果的なシチュエーションダウン&ディスタンスを問わず使える基本セット。特に1st down、2nd&ミディアムなど、複数のプレー選択肢を残したい場面で多用される。
代表的なコンセプトインサイド・ゾーン、アウトサイド・ゾーン、フォー・バーティカルズ

シングルバック・エース SINGLEBACK ACE

パーソネル: 12（RB1 / TE2 / WR2）

両TEでランを厚くしつつ、PAの脅威も残す

TEを両サイドに1人ずつ配置し、WRを2人に絞った隊形。ブロッカーの頭数を増やしてランを厚くしつつ、TEを使ったプレーアクションパスにも展開できる。

構成内容
パーソネル12（RB1 / TE2 / WR2）
ポジション構成QB1・RB1・TE2（Y, H, ともにインライン）・WR2（X, Z）。TEが両側のエッジをブロックで固められるため、OLの人数以上の「実質7人ライン」が作れる。
特徴・用途TE2人分のブロック力でランをサポートしつつ、片方のTEをリリースさせるプレーアクションが効果的。ボックス内の人数調整（守備が重くなりやすい）を誘発できる。
効果的なシチュエーションショートヤーデージや、ランを見せてから深いパスを狙うプレーアクション、悪天候などパスを絞りたい試合展開で選ばれやすい。
代表的なコンセプトデュオ、カウンター、ダガー

シングルバック・ジャンボ SINGLEBACK JUMBO

パーソネル: 13（RB1 / TE3 / WR1）

ラインを事実上8人に厚くし、強サイドにPAの脅威を残す

「シングルバック・エース」に3人目のTEを加え、WRをZ1人に絞った最重量級のジャンボパッケージ。弱いサイドにTEを2人並べてラインを事実上8人まで厚くし、強いサイドのYとZでプレーアクションの脅威も残す。

構成内容
パーソネル13（RB1 / TE3 / WR1）
ポジション構成QB1・RB1・TE3（Y, H, U, いずれもインライン）・WR1（Z）。弱いサイドにH・Uの2人のTEを並べてラインを実質8人まで厚くし、強いサイドはYとZでプレーアクションの脅威を残す。
特徴・用途TE3人分のブロック力でランを最大限に厚くしつつ、強いサイドのYを外に出すプレーアクションや、Uをリリースさせる意表を突いたパスも選択肢になる。守備をボックスに寄せやすい最重量級の隊形。
効果的なシチュエーションショートヤーデージ・ゴール前・試合終盤のクロックマネジメントなど、ランを最優先したい場面。悪天候でパスを絞りたい試合展開でも選ばれやすい。
代表的なコンセプトパワー、アイソ、ダガー

ショットガン・スプレッド SHOTGUN SPREAD

パーソネル: 10（RB1 / TE0 / WR4）

守備を横に薄く伸ばし、ボックスの人数を減らす

TEを置かずWR4人を横に大きく広げ、QBをショットガンに下げるパス特化の隊形。守備を横に薄く伸ばし、ボックスの人数を減らしてランのスペースも作る。

構成内容
パーソネル10（RB1 / TE0 / WR4）
ポジション構成QB1（ショットガン）・RB1・TE0・WR4（X, H, Y, Z を均等配置）。4人のWRが守備のカバレッジ人数を分散させ、シンプルな数的優位を作りやすい。
バリエーション10パーソネルのフルスプレッドに加え、11パーソネルでTEをスロット的に割り出して同じシェイプを作る形も多用される。パーソネル変更なしでシングルバックのランへオーディブルしやすいのが利点。
特徴・用途守備をワイドに広げることでボックス内のLB/DLの人数を減らせるため、見た目以上にランの効率も上がる。ノーハドルなどテンポ勝負とも相性が良い。
効果的なシチュエーションパスダウン（2nd/3rd&ロング）や、守備の人数配置を広げてからランを差し込みたい場面で有効。
代表的なコンセプトスラント、スティック、メッシュ、レベルズ、スマッシュ、ダガー、フォー・バーティカルズ、ポスト・ホイール

ショットガン・トリップス SHOTGUN TRIPS

パーソネル: 11（RB1 / TE1 / WR3）

1つのゾーンに脅威を集め、ミスマッチを作り出す

WR3人を片方のサイドにまとめて並べ（トリップス）、逆サイドにTEを1人残す隊形。1つのゾーンに複数の脅威を集め、その方向の守備にミスマッチや人数不足を作る。

構成内容
パーソネル11（RB1 / TE1 / WR3）
ポジション構成QB1（ショットガン）・RB1（TE側にオフセット）・TE1（Y, 左インライン＝バックサイド）・WR3（右にトリップス W, H, Z）。トリップス側に守備の的を絞らせつつ、逆サイドのTEで数合わせをする。
特徴・用途トリップス側のゾーンに守備を密集させ、その内部でレシーバー同士がピック（クリアランス）を作りやすい。逆サイドのTEはブロックにもルートにも使える保険。
効果的なシチュエーショントリップス側のフィールドを広く使いたいパスプレー、あるいは守備をずらしてからバックサイドへランを差し込みたい場面で有効。
代表的なコンセプトフラッド、レベルズ、スティック

ショットガン・バンチ SHOTGUN BUNCH

パーソネル: 11（RB1 / TE1 / WR3）

密集配置が生む自然なピックで、マンのズレを作る

WR3人を片方のサイドに、横一列のトリップスではなくトライアングル型に密集させる（バンチ）隊形。レシーバー同士が近いためリリース時に自然なピック（クリアランス）が生まれ、マンカバレッジのマッチアップを乱しやすい。逆サイドにはTEを1人残す。

構成内容
パーソネル11（RB1 / TE1 / WR3）
ポジション構成QB1（ショットガン）・RB1（TE側にオフセット）・TE1（Y, 左インライン＝バックサイド）・WR3（右側にバンチ：Zがライン上の点、H・Wがその内側後方に並びトライアングルを形成）。トリップスと異なり、3人を数ヤード四方に密集させて自然なピックを作る。
特徴・用途3人が近接するため、リリース時にディフェンダー同士がぶつかる自然なピック（レリースピック）が起きやすく、マンカバレッジで受け渡しのミスを誘発する。ゾーン守備に対しても、狭いエリアに複数の脅威を置くことで的を絞らせにくい。
効果的なシチュエーションマンカバレッジが濃厚な場面で、レシーバー同士のクリアランス（ピック）を使ってオープンを作りたいとき。ショートヤーデージでのクイックゲインや、レッドゾーンでのマッチアップ操作にも有効。
代表的なコンセプトスポット、フラッド、スティック

エンプティ EMPTY

パーソネル: 01（RB0 / TE1 / WR4）

5人全員を脅威にし、守備の意図を早く見極める

バックフィールドにRBを置かず、5人全員をレシーバーとして展開する隊形。守備の意図（マンかゾーンか、ブリッツか）をプレスナップで読み取りやすくなる。

構成内容
パーソネル01（RB0 / TE1 / WR4）
ポジション構成QB1（ショットガン、バックフィールドは無人）・RB0・TE1（Y, 右インライン）・WR4（左にトリップス X, H, W／右に Z）。5人全員が同時にルートへ出られる。
バリエーション01パーソネルのフルエンプティに加え、11パーソネルでRBをスロットやワイドアウトへ展開する形も多用される。パーソネル変更なしでシングルバックのランへオーディブルしやすいのが利点。
特徴・用途RBが不在のためパスプロテクションは薄くなるが、守備は全員に対応する人数を割かざるを得ず、ミスマッチを作りやすい。QBのプレスナップリードの材料も多い。
効果的なシチュエーション3rd&ロングなど明確なパスダウンや、守備のマン/ゾーンを見極めたい場面で使われる。ラン警戒を解いてパスに全振りする意図が明確。
代表的なコンセプトレベルズ、ダガー、スティック

ピストル PISTOL

パーソネル: 11（RB1 / TE1 / WR3）

ショットガンのパスタイミングと、Iフォームのラン角度を両立

QBをショットガンより浅い位置（約4yd）に置き、RBをさらにその後ろに縦列させる隊形。ショットガンのパスタイミングとIフォーメーションに近いランの角度を両立する。

構成内容
パーソネル11（RB1 / TE1 / WR3）
ポジション構成QB1（ピストル、深さ約4yd）・RB1（QBの直後、約7yd）・TE1（Y, 右インライン）・WR3（X, H, Z）。RBがQBの背後に隠れることでランの方向が読まれにくい。
特徴・用途RBがQBの真後ろにいるため左右どちらにも同じ角度でハンドオフでき、ランの方向を隠しやすい。ショットガンよりQBのパスへの視界確保もしやすい。
効果的なシチュエーションゾーンラン（インサイド/アウトサイド）とプレーアクションパスを高い頻度で織り交ぜたいオフェンスの主力セット。
代表的なコンセプトインサイド・ゾーン、アウトサイド・ゾーン、ポスト・ホイール、フラッド

アイフォーメーション I-FORMATION

パーソネル: 21（RB2 / TE1 / WR2）

FBのリードブロックで、パワー系のランに数的優位を作る

QBの直後にFB、さらにその後ろにHBを縦一列（I字）に並べる伝統的な隊形。FBがリードブロッカーとしてホールを切り開き、パワー系のランを支える。

構成内容
パーソネル21（RB2 / TE1 / WR2）
ポジション構成QB1（アンダーセンター）・RB2（FB+HB, 縦列）・TE1（Y, 右インライン）・WR2（X, Z）。バックフィールドの厚みでランのパワーを最大化する構成。
特徴・用途FBがLBを直接ブロックしてホールを作る、力対力のダウンヒル・ランが持ち味。バックフィールドが深いためQBのプレーアクションも効きやすい。
効果的なシチュエーションショートヤーデージ、ゴール前、クロックを進めたい終盤の「地上戦」で強みを発揮する。守備に対し明確なラン意図を示す隊形でもある。
代表的なコンセプトパワー、アイソ、ポスト・ホイール、スマッシュ

プロセット PRO SET

パーソネル: 21（RB2 / TE1 / WR2）

Iフォームより横に広がりつつ、2バックの厚みを維持する

FBとHBをQBの後方で左右にオフセット（ずらして配置）した隊形。Iフォーメーションよりも横への広がりを持たせつつ、2バックの厚みは維持する。

構成内容
パーソネル21（RB2 / TE1 / WR2）
ポジション構成QB1（アンダーセンター）・RB2（FB+HBをオフセット配置）・TE1（Y, 右インライン）・WR2（X, Z）。2バックを保ちながらアウトサイド・ゾーンなど横方向のランにも対応できる。
特徴・用途Iフォーメーションよりもブロッキング角度に柔軟性があり、ラン・パスどちらの起点にもなりやすい。FBを片側のフレックスに出してミスマッチを作ることも可能。
効果的なシチュエーションオールラウンドな2バックオフェンスの基本セット。ランを軸にしつつパスプロテクションの厚みも欲しい場面で使われる。
代表的なコンセプトアウトサイド・ゾーン、パワー、ポスト・ホイール、スマッシュ

ワイルドキャット WILDCAT

パーソネル: 21（RB2 / TE1 / WR2）

QBを空けて、ブロッカー1人分の数的優位を作る

センターからQBではなくRBへ直接スナップする変則隊形。本来のQBはWRの位置に開き、守備にブロッカー1人分の人数的優位を作る。

構成内容
パーソネル21（RB2 / TE1 / WR2）
ポジション構成RB2（直接スナップを受けるボールキャリア＋リードブロッカーのFB）・TE1（Y, 右インライン）・WR2（X, Z）に加え、本来のQBはスロットへ「WRのように」開く。QBはパサーではなくなるが、フィールド上の人数（11人）は変わらない。
特徴・用途スナップの瞬間からQBの「ハンドオフの間」が消えるため、守備の反応が一瞬遅れやすい。FBのリードブロックとオプション的な進行方向の選択でディフェンスを揺さぶる。
効果的なシチュエーションショートヤーデージや変則プレーとして単発で使われることが多く、頻度を上げすぎず奇襲性を保つのが基本。
代表的なコンセプトパワー、カウンター

ゴールライン・ジャンボ GOAL LINE JUMBO

パーソネル: 22（RB2 / TE2 / WR1）

エッジを固めた最重量級で、短い前進を確実に取りに行く

TEを両サイドに配置してエッジを固め、RBを2人重ねた最重量級の隊形。ゴール前やショートヤーデージで、少ない前進距離を確実に取りに行く。

構成内容
パーソネル22（RB2 / TE2 / WR1）
ポジション構成QB1（アンダーセンター）・RB2（FB+HB, 縦列）・TE2（Y, H, ともにインライン）・WR1（Z）。ブロッカーの絶対数を最大化し、守備の1対1を数の力で上回る構成。
特徴・用途ライン戦での人数的優位を作ることに特化しており、ランプレーの選択肢は絞られる分、各アサインメントの精度が高い。さらにOLを1人増やす「ジャンボ」変形（6人OL）が使われることもある。
効果的なシチュエーションゴール前や4th&ショートなど、1〜2ydを確実に取りたい場面の定番。守備側にも重い人数配置（ゴールラインディフェンス）を強いる。
代表的なコンセプトパワー、アイソ

各図は概念説明用の簡易ダイアグラムであり、選手間の距離・角度は実際のプレーコールにより異なる。パーソネルの数字は「RBの人数・TEの人数」を表し、残りはWRとして扱う（例: 11 = RB1・TE1・WR3）。
